# 故障排查

遇到问题时，先查看 `Library/.logs/` 下的日志：`tak-*.log` 是 TAK 自身日志，`tdl-*.log` 是下载引擎的原始日志。以下是常见问题的处理方法。

## 下载相关

### 登录检查正常，但下载一直 0 B/s

这不矛盾：基础 Telegram 会话可用，不代表媒体所在的数据中心（DC）当前正常。tdl 在 Windows 上存在公开的"下载进程不退出但长期 0 B/s"问题（[iyear/tdl#1071](https://github.com/iyear/tdl/issues/1071)）。

TAK 默认 60 秒无真实进展后自动暂缓当前活动媒体、重建缺失队列先下载其他文件，并在预算内做一次诊断性重启，无需干等几个小时。

如仍反复失败，按顺序尝试：

1. 在「下载设置」中恢复推荐值：并发 2 × 线程 4；
2. 显式配置代理；
3. 查看 `Library/.logs/` 中 tdl 的原始日志；
4. 用「设置与诊断 → 环境诊断」确认 tdl 版本与会话状态。

### 部分媒体反复失败

- 疑难文件会进入独立重试队列（默认每轮 3 次，可配置 1–10），不会阻塞其他文件；
- 全部预算耗尽后，程序会结束并列出失败媒体的 Message ID——可以根据 ID 单独排查（例如该媒体已被发送者删除、或 DC 临时故障）；
- 疑难文件的重试传输策略可在「下载设置」中调整（默认逐步增大线程）。

### 下载中断后要重新下载全部吗？

不需要。TAK 以**实际存在的完整文件**为准重新计算缺失清单（不信任下载器的中断状态），0 字节残留会自动清除。重新执行同步即可从断点继续。

### 下载很慢 / 想加快

- 并发与线程可在「下载设置」调整（1–8 × 1–16），但过高容易触发服务端限流，推荐 2×4；
- 确认没有代理绕路；直连通常更快；
- 使用「同步全部聊天」可以逐库批量处理，无需盯着单个聊天。

## 登录相关

### 扫码/验证码登录失败

- 确认系统时间准确；
- 验证码输入有次数限制，失败后稍等再试；
- 会话保存在 `%USERPROFILE%\.tdl\`，异常时可在菜单「Telegram 账号与会话 → 打开会话目录」检查，必要时删除该目录重新登录（需重新扫码，不影响已下载数据）。

### 提示 tdl 未安装

程序会自动从 tdl 官方 GitHub Release 下载安装。若网络受限导致自动安装失败：

- 手动从 [tdl releases](https://github.com/iyear/tdl/releases) 下载对应平台的压缩包，解压出 `tdl.exe` 放入 PATH，或放到 `%LOCALAPPDATA%\Programs\tdl\tdl.exe`；
- 然后在「设置与诊断」中重新检测。

## 网页相关

### 网页样式错乱 / 看不到新功能

浏览器缓存了旧版 CSS/JS：

1. 确认已用**新版本程序**执行过「只重新生成网页」；
2. 关闭旧标签页重新打开，或按 `Ctrl+F5` 强制刷新。

### 图片/视频没有缩略图或封面

- 视频海报帧和 HEIC/WebP 解码需要 FFmpeg，程序会在需要时自动安装；网络受限时可[手动安装 FFmpeg](https://www.gyan.dev/ffmpeg/builds/)，确保 `ffmpeg -version` 可用后重新生成网页；
- 极少数编码异常的媒体即使有 FFmpeg 也无法解码，数量记录在 `archive-report.json` 的 `missing_image_previews` / `missing_video_previews` 中，媒体本身不受影响。

### 显示"媒体尚未同步"

该消息的媒体还没有下载完成。重新执行「一键完成」或「聊天管理 → 一键同步」，补齐后标记自动消失。个别媒体确认无法下载时（如发送者已删除），会保留标记并在报告中说明。

### 移动端/小屏布局问题

网页对 320–1920px 宽度做了响应式适配。若在特定浏览器上出现问题，请提 Issue 并附上浏览器类型与截图。

## 磁盘与迁移

### 跨盘迁移中断了怎么办？

跨盘复制使用 `.tak-part` 临时文件，中断不会损坏任何已有文件。重新发起迁移即可从断点继续（同名同大小的文件自动跳过）。

### 磁盘空间不足

- 环境预检会给出下载所需空间的预估，请在开始前确认；
- 引用官方 ChatExport（零复制模式）可以避免为历史导出复制一份媒体；
- 缩略图缓存 `thumbs/` 可在关闭缩略图功能后删除，不会影响媒体与消息。

## 其他

### 程序双击后一闪而过

本程序是**控制台（TUI）程序**，正常情况下会打开一个终端窗口。如果窗口立即退出，请在 PowerShell/CMD 中手动运行 exe 查看错误输出，并提交 Issue 附上内容。

### 程序无响应

查看 `Library/.logs/tak-*.log` 的最后几行定位当前操作。缩略图生成、跨盘复制等长任务使用后台低优先级，界面可能暂时不刷新但仍在工作。

### 仍无法解决

提交 [Issue](https://github.com/Kkwans/telegram-archive-kit/issues)，请附上：

1. `TelegramArchiveKit.exe version` 的输出；
2. `Library/.logs/` 中相关日志（**先抹去个人聊天内容**）；
3. 问题的具体操作步骤与预期/实际表现。
